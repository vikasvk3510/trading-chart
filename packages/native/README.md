# tradingcandle-react-native

React Native trading chart. `react-native-webview` loads `chartHtml`, a single HTML document with the chart script inlined. No network is required to boot the chart.

`chart.html` in this package is the same document, for a Kotlin or Swift WebView.

See the repository [README](../../README.md). Apache-2.0. KLineChart is Apache-2.0.
